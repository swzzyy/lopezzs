# Lopes — Site de Bio

Site de bio simples, responsivo e gratuito para publicar no GitHub Pages.

## Antes de publicar
Abra `index.html` e troque:
- `@lopes` pelo seu Instagram
- os links `href="#"` pelos seus links reais
- a descrição pelo texto que quiser
- o avatar "L" por uma foto, se desejar

## Publicar no GitHub Pages
1. Crie uma conta em https://github.com/ (se ainda não tiver).
2. Crie um novo repositório chamado `lopes.github.io` — substitua `lopes` pelo seu nome de usuário do GitHub.
3. Envie `index.html`, `style.css` e `script.js` para o repositório.
4. No GitHub, abra Settings → Pages.
5. Em Source, escolha Deploy from a branch.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a publicação.

Seu endereço ficará parecido com:
https://SEU-USUARIO.github.io/

Não é necessário pagar mensalidade para usar o GitHub Pages em um site pessoal simples.
